Controles
Celular y tablet: un dedo gira; dos dedos desplazan y acercan. Doble toque sobre el modelo enfoca.
Computadora: arrastra para girar; rueda para zoom; botón derecho o Mayús para desplazar. Doble clic para enfocar.
Interior: arrastra para mirar; usa las flechas en pantalla o W, A, S, D para recorrer. Q / E bajan / suben.
Atajos: H vista limpia · F pantalla completa · R vista general · Esc salir.

El modelo original y sus texturas están incluidos. La cubierta comienza oculta para que puedas apreciar la distribución; actívala para ver el volumen completo. Puedes descargar el visor HTML para abrir esta presentación sin conexión.
